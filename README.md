# Current

A mobile-first field operations and inventory prototype for electrical contractors.

It includes an operational home dashboard, job board, inventory search, low-stock alerts, and navigation between views.

## Try it on an iPhone

Deploy these static files to any HTTPS host (GitHub Pages, Netlify, or Cloudflare Pages), then open the public URL in **Safari** on the iPhone. Tap **Share** → **Add to Home Screen** → **Add**. The installed app launches without browser controls and caches its interface for offline use.

For a same-Wi-Fi preview during development, serve this folder from your computer with a local web server and open the computer's local network address on the iPhone. A hosted HTTPS URL is required for the installable/offline version.
